# 咻咿提取 · 电脑助手

手机安装 4.0.24 或更高版本，进入“微信表情导入”。两种方式可以同时使用：

1. **离线 ZIP**：在电脑助手选择“导出微信表情”和自己的表情库，阅读并勾选说明，点击“导出 ZIP 到电脑”。将得到的 ZIP 自行传到手机，点击“选择 ZIP 导入”。这条路线不启动局域网监听。
2. **连接电脑助手**：运行 Windows 助手，手机与电脑连接同一局域网。选择模式、文件和本机局域网地址，启动后复制配对内容到手机的“连接电脑助手”，点击“连接并获取”。

助手模式：

- **导出微信表情**：登录电脑微信，打开“我添加的表情”面板，选择自己账号的 `db_storage/emoticon/emoticon.db`。阅读并勾选风险说明，再启动。手机请求后，电脑读取这份表情库的配置、在内存解析并向微信媒体服务器下载，随后发送 ZIP。微信版本变化可能导致不兼容。原验证版本为 Windows 微信 4.2.0.13。
- **传送已有 ZIP**：选择已导出的 ZIP，不读取微信进程或数据库。手机请求时传送选定文件。

配对内容包含临时访问凭据，请只粘贴到自己的手机。连接采用 HTTPS，并由手机校验配对内容中的证书指纹；配对有效期一小时，停止或重启后失效。助手只监听选定的本机局域网地址，不需要云服务器。表情库密钥和媒体地址不传给手机，不记录访问令牌。手机取消接收不会中断电脑已经开始的导出；停止助手会使旧配对失效。

若连接失败，检查所选 IP、同一局域网，以及 Windows 专用网络对该程序的防火墙许可。不要关闭防火墙或配置公网端口转发。

**非官方导出仍有账号风险，不能保证不会触发微信风控。** 本工具不是微信官方接口。只处理自己的账号和表情；需要规避这类导出风险时使用已经合法取得的原文件 ZIP。

## 从源码运行

需要 Windows、Python 3.11+。在本目录执行：

```powershell
python -m pip install -r requirements.txt
python helper.py
```

`vendor/` 中复用并裁剪了 Ant39140/wechat_meme_export 的 MIT 许可代码，仅调用与所选表情库匹配的配置读取路径；许可证位于 `vendor/LICENSE`。
