# DouYinGetting

抖音评论媒体提取验证项目，包含 Android App 源码、浏览器端提取脚本和设计记录。Android debug APK 已构建；App 内登录、完整扫描和批量保存仍需真机验证。

## 已验证

- 用户登录的 Chrome 页面可读取本样本作品的评论分页响应。
- 评论数据提供图片列表，以及表情的静态和动画地址。
- 提取器按实际文件格式保存 JPEG、PNG、WebP、GIF；GIF 保留多帧动画。
- `manifest.json` 记录扫描评论数、去重后的文件、来源评论 ID、格式、帧数和下载失败项。`scope: primary_comments` 表示结果只覆盖主评论；`complete` 只表示主评论分页是否到达终点。

## 运行

1. 安装 `requirements.txt` 中的 Python 依赖。
2. 用带远程调试端口的 Chrome 打开目标作品，并由用户自行扫码登录。当前验证会话使用端口 `9232`。
3. 运行：

   ```powershell
   python extract_comments.py 7707515663400689257 --port 9232 --max-pages 3
   ```

   输出位于 `exports/7707515663400689257/`。省略 `--max-pages` 会尝试扫描到末页；连续多次未加载新页时停止并保留部分结果。

## 当前限制

- 该提取器依赖用户自行登录后的浏览器会话，不读取抖音 App 的登录数据。
- 样本作品已读到主评论分页终点：扫描 459 条主评论，保存 193 个去重媒体文件，其中 22 个多帧 GIF。还有 1 个媒体响应无法识别为图片，已在清单中记录。
- 首版范围只包括主评论；评论回复暂不做。
- 媒体地址会过期；程序在扫描时立即下载。页面结构和接口可能变化。

## Android 源码

`android/` 是无第三方运行库的 Android 工程。打开作品后，用户在 App 内登录抖音并进入评论区，点击“扫描主评论”；App 按游标读取主评论，把媒体原文件暂存于应用目录，支持预览和保存到 `下载/DouYinGetting`。动图以原始文件格式保存。

已使用 `E:\Android\Sdk`、JDK 17 和 Gradle 8.14.3 从**项目根目录**构建 debug APK：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-17'
$env:ANDROID_HOME = 'E:\Android\Sdk'
gradle :app:assembleDebug
```

生成文件为 `android/app/build/outputs/apk/debug/app-debug.apk`。已在本机模拟器安装、启动并打开样本链接；应用内登录、主评论完整扫描和批量保存尚需在真实 Android 环境验证。

登录二维码需要用普通抖音 App 的“扫一扫”；抖音极速版扫码会提示改用抖音扫一扫。若只有一台手机或只使用极速版，可在 App 内打开抖音网页登录框后点“切换验证码登录”，由抖音网页完成手机号验证。此入口是否在所有抖音网页版本可用仍需真机验证。

抖音可能在登录后另行要求身份验证（如刷脸或扫码），这一步由抖音决定，App 无法跳过。版本 0.3 支持网页申请相机：只有用户在 App 的确认弹窗和 Android 权限弹窗都同意后，才向验证网页提供相机；扫描和保存评论图片不需要相机。刷脸验证是否能在抖音的嵌入网页中完成仍需真机验证。

版本 0.4 在点击扫描时也会读取网页已有的评论请求记录，避免评论区先打开、请求已发出时一直等待。等待约 15 秒仍找不到请求会提示刷新作品并重新打开评论区。

版本 0.5 不再限定评论接口必须使用单一主机和固定路径，并在等待超时后显示实际见到的评论相关请求路径，供真机排查。当前 WebView 使用抖音电脑端页面以复用网页评论接口；手机页面体验仍需单独改造。

版本 0.6 修复 WebView 返回 JSON 对象时的类型转换错误；接收对象或 JSON 字符串均可继续解析。末页游标不变时可正常结束扫描。

版本 0.7 在评论接口拒绝重发请求时显示 HTTP 状态、抖音状态码及错误说明，供真机定位拒绝原因。

版本 0.8 修复异步请求时序：网页发起评论请求后先把结果写入页面变量，Android 轮询到请求完成才解析结果，最多等待约 20 秒。此前的 `HTTP -1` 是把尚未完成的 JavaScript Promise 当作接口响应。

版本 0.9 增加功能入口页和独立的抖音链接读取页。读取页在结果产生后默认以三列缩略图预览图片与 GIF，动图自动播放；点击缩略图可放大并单独保存，也可批量保存。网页登录和打开评论区仍在读取页的“网页操作”区域完成。界面设计稿位于 `design/ui/`。

版本 1.0 每次新扫描会在 App 私有目录创建独立的暂存记录，保存链接、时间、主评论扫描进度和媒体原文件。可重新查看记录或删除记录及其暂存文件；下载目录中已另行保存的文件不受删除影响。暂存记录保留到用户主动删除或卸载 App。旧版 App 私有目录中已有的媒体会作为一条“旧版提取结果”显示，来源链接无法恢复。

版本 1.1 将扫描记录入口移到抖音链接读取页右上角，点击后可查看或删除暂存记录。单张和批量保存结束时均显示成功、失败或部分成功提示；批量提示列出成功与失败数量。

版本 1.2 在主评论扫描到末页、素材处理完毕后弹出完成提示，显示扫描评论数和提取素材数，并提供“查看结果”按钮。
