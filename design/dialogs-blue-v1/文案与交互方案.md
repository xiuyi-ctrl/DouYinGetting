# 咻咿提取 · 弹窗美术与文案方案 V1

本轮仅提供设计，不修改 Android 代码、不构建 APK。数字、域名、时间、文件规格和失败原因均为排版示例，接入时必须使用真实数据。

## 设计交付

- `dialogs-light.png`：删除记录、取消收藏、扫描暂停、部分保存失败、备份失败、相机授权，六类浅色弹窗。
- `dialogs-dark.png`：对应的六类深色弹窗。
- `details-preview.png`：扫描明细、选择失败项、素材预览。
- `waiting-about.png`：导入导出等待状态、关于咻咿。
- `index.html`：可切换深浅色和三组组件的预览；按钮仅作设计演示，不执行真实业务。
- `generate.py`、`render.ps1`：设计稿生成与截图脚本。

## 统一美术规范

沿用应用 B 方向蓝色：浅色主色 #456BFF，深色主色 #708CFF；危险操作使用红色。图标统一 24 网格、1.8 线宽，不使用系统默认杂色图标。

| 项目 | 建议 |
|---|---|
| 卡片 | 最大宽 320 dp，两侧至少 24 dp；高度随内容变化；圆角 24 dp |
| 内边距 | 常规 22 dp，列表和预览 20 dp |
| 图标 | 24 dp 线性图标，42 dp 浅色容器；危险操作淡红底 |
| 标题 | 19–20 sp / 750，尽量一行；大字体时允许换行 |
| 正文 | 13–14 sp / 400，行高约 22 dp；优先两到三行 |
| 按钮 | 13–14 sp / 650，高度至少 44 dp，间隔 10 dp |
| 次按钮 | 浅灰底、正文色；避免与主按钮都使用蓝色 |
| 主按钮 | 蓝底白字；删除、取消收藏的确认操作使用红色 |
| 遮罩 | 浅色约 28% 深色遮罩，深色约 55%；不能只靠颜色区分危险操作 |
| 动效 | 180 ms 淡入并从 0.97 缩放至 1；关闭 140 ms 淡出；跟随“页面动效”开关 |
| 列表 | 内容区限高并独立滚动；标题和底部按钮固定，弹窗不超出安全区域 |

不同时放置右上角关闭图标和底部“关闭”按钮。素材预览保留底部“关闭”，与收藏、分享、保存保持四个按钮一行。

## 文案原则

1. 标题直接描述对象、动作或结果，避免“提示”“操作未全部完成”等笼统标题。
2. 正文说明影响和下一步，不复述标题；明确区分暂存素材、收藏文件、下载文件。
3. 按钮使用具体动作，如“继续扫描”“重新选择”“删除记录”，不用“确定/是/否”代替关键动作。
4. 不把 HTTP -1、JSON 解析异常或堆栈直接当作文案。可识别原因用中文说明，无法识别时使用通用原因；技术信息可在明细中查看。
5. 不将所有读取失败都描述为风控、登录过期或限流，除非接口明确返回了对应原因。
6. 成功提示继续使用轻提示，不恢复为弹窗。带跳转按钮 4 秒，普通反馈 2 秒；保存、收藏等操作反馈显示在底部。

### 失败原因的分支

- 备份格式不支持：`这不是受支持的记录备份。`
- 备份损坏或缺文件：`备份文件不完整，缺少部分素材。`
- 导出位置不可写：`无法写入所选位置。`
- 存储不足：仅确认空间不足时显示 `设备可用空间不足，请清理后重试。`
- 网络连接中断：仅对应真实网络错误显示 `网络连接中断，请检查连接后重试。`
- 原因未知：`当前无法完成此操作，请稍后重试。`
- 不在界面宣称“备份已删除”“所有原文件完整”等尚未验证的结果。

## 各类弹窗的交互边界

- **删除与取消收藏**：保留确认。点击遮罩或返回键视为取消，不执行删除。
- **扫描暂停**：不自动消失；“继续扫描”沿用当前页重试逻辑，“稍后再试”关闭弹窗并保持暂停。
- **失败反馈**：保留直到用户关闭。美术稿不新增未实现的“只重试保存失败文件”等按钮。
- **扫描明细**：主评论、回复、素材分开统计；没有异常时显示“本次未记录异常”，没有失败项时隐藏重试按钮。
- **选择失败项**：按“失败素材”“回复组”组织，整行可点；不能把回复组编号伪装成平台真实的评论顺序。示意的“01”只表示本列表编号。
- **素材预览**：四个底部按钮始终一行，保存为主操作；取消收藏文字较长时允许去掉图标，保留完整文字和触摸区域。
- **等待状态**：当前没有可靠的阶段进度，使用转动图标，不用示例百分比。若后续拆分为检查/解压/恢复阶段，必须由实际任务状态驱动。
- **系统窗口**：文件选择、分享面板和系统相机权限不自绘替代；只优化打开前的应用内说明。

## 接入时需要的数据

当前已有的计数、失败列表和相机来源可以直接使用。以下内容应按实际数据接入，不是本轮已实现功能：

- 预览副标题中的尺寸与大小：读取文件实际信息，未知项隐藏。
- 明细列表中的时间与失败原因：有记录才展示，旧记录没有时间时不补造。
- 错误原因分类：优先识别文件缺失、写入失败、空间不足等明确错误，未知错误使用通用说明。
- 失败详情中的链接或标识：默认收起，避免长 URL 把主要说明挤出屏幕。

## 验收建议

覆盖浅色、深色、长标题、200% 系统字体、0/1/多条失败项、长域名、长文件名和窄屏；按钮不重叠，内容内部可滚动，不遮挡系统手势区域。普通成功反馈仍按现有轻提示规则展示。
