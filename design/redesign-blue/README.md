# B 方向设计稿

由内置 imagegen 生成的概念设计，图中数字、素材为示例。
主色 #456BFF，浅色背景 #F4F6FA，深色背景 #0D1320，深色卡片 #1A2436。
主要页面采用 16 dp 圆角和清晰中文无衬线字体。英文标题使用 Manrope 风格几何无衬线字体。

- main-pages.png 展示浅色首页、收藏、我的。
- extraction-settings-dark.png 展示浅色读取页、设置页、深色首页及收藏多选。
- 首页标题固定为 Xiuyi extraction。标题解码 0.8 秒，初次进入首页播放一次，布局尺寸固定。
- 收藏、首页、我的保持底部导航。切换约 220 ms，内容轻移和淡入，选中背景同步移动。
- 设置页和读取页使用返回入口，各主要页面右上角提供设置。
- 设置支持浅色、深色、跟随系统。整卡开关包括读取回复、快速扫描、标题解码、页面动效。
- 我的提供收藏/记录计数、扫描记录、本机存储、保存位置、关于。
- 读取页提供记录入口，实施时安排在设置左侧或页面内，保留现有功能。
- 概念图扫描条表示不确定进度，实施时使用活动动画，不推算百分比。
- 首屏贴纸是候选装饰素材，不代表替换 App 图标。
