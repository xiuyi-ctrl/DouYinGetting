## 字体与颜色

中文 Noto Sans SC：标题18/750、主按钮14/700、扫描标题16/750、网页操作13/650、分类12/650、说明12/400、底部统计14/750。数字为字号sp / 字重。

浅色：页面 #F4F6FA、卡片 #FFFFFF、正文 #0F172A、次文字 #536176、描边 #DCE2ED、主色 #456BFF。
深色：页面 #0D1320、卡片 #1A2436、正文 #F3F6FF、次文字 #BEC9DC、描边 #303E55、主色 #708CFF。
页面边距16dp；卡片圆角12–14dp；操作按钮间距10dp；扫描状态不使用虚假百分比。

## 动效规范

- 分类：220ms蓝色选中背景滑动、结果按切换方向轻移淡入。
- 主按钮、保存、预览项：100–120ms按压至0.96后恢复。
- 多选圆点：150ms淡入缩放，选中边框同步变蓝。
- 网页操作：180ms箭头旋转及展开高度过渡。
- 保存：下载图标轻移；成功或失败反馈以真实结果为准，原有提示保留。
- 所有装饰性动效与设置中的「页面动效」共享。关闭后立即切换；不改变原文件的动图播放逻辑。
